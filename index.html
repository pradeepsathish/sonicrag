What actually broke, and how it got fixed
Kept in on purpose — this is more useful in an interview than a clean number with no story behind it.
Chroma-argmax key detection: 16.7% accurate
Raw chroma picks the most-played pitch class, not the tonic. Fixed with Krumhansl-Schmuckler key-profile correlation across all 24 rotations — took accuracy to 93.8%.
Text parser matched stray letters as notes
"chords" contains the letter c, which got parsed as the key of C. Fixed by requiring the note adjacent to major/minor, or after "in"/"key of".
Zero-padded query vectors drowned out real signal
Forcing a 3-field query into a 144-dim vector with 128 zeroed mel dimensions let the zeros dominate cosine similarity. Fixed with explicit per-field weighted scoring instead.
What this is not
No Kafka ingestion, no Ray worker pools, no HNSW sharding, no 22ms p95 latency claim over 10M vectors. Those were fabricated numbers in an earlier draft of this project with no code behind them. Production-scale serving is a real infra project — it isn't simulated here, and it isn't claimed here.
